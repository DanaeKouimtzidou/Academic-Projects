# Hotel Reservation System

A desktop-based Hotel Reservation System developed in Java using Java Swing.

## Technologies

- Java
- Java Swing
- Object-Oriented Programming (OOP)

## Features

- Hotel room management
- Customer management
- Room reservation creation
- Room availability tracking
- Revenue calculation
- Support for all-inclusive reservations
- Input validation
- Multiple room types (Single, Double, Suite)

## Project Structure

- Customer
- Room
- Reservation
- AllInclusive Reservation
- Hotel
- InputFrame (GUI)
- Main

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Run the `Main.java` class.

## Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Inheritance
- Method Overriding
- Encapsulation
- Java Swing GUI
- Event Handling
- Collections (ArrayList)
- Exception Handling
